## Trabajo unidad 1 y 2:

El Micromecenazgo o Crowfunding, es una red de financiación colectiva de proyectos o causas. A través de donaciones se consigue obtener los recursos económicos para que un proyecto o causa pueda llevarse a cabo. Estas donaciones generalmente son online, se pueden recibir a cambio recompensas o puede ser de forma altruista.

Existen varios modelos de micromecenazgo, de los cuales destacan principalmente:
- De donaciones: Las personas hacen aportaciones de manera altruista, es decir, sin recibir nada a cambio.
- De recompensas: Las personas reciben una recompensa por su contribución (Por ejemplo: si el proyecto es un libro: una copia del libro).
- De royalties: Cuando se espera obtener una parte, aunque sea simbólica, de los beneficios del proyecto o de la empresa.

En este tipo de webs generalmente se apoya un proyecto o causa o varias causas, pudiendo un usuario aportar/ donar o incluso proponer un proyecto. 
A lo largo de este Módulo realizaremos el código para llevar a cabo el front-end de esta aplicación.
